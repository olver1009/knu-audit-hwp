# 감사 비용처리서 HWP

영수증·거래명세서·구매내역을 읽어 경북대학교 감사 비용처리서 HWP를 작성하는 ChatGPT/Codex 플러그인입니다.

## 무엇이 들어 있나

- 플러그인: `knu-audit-hwp`
- 작업 스킬: `knu-audit-expense`

설치 단위는 플러그인이고, 실제 비용처리서 작성 절차는 플러그인 안의 스킬이 수행합니다.

## Work에 가져오기

워크스페이스 관리자 계정에서 다음 순서로 가져옵니다.

1. **Admin → Plugins → Add → Import marketplace**를 엽니다.
2. **Source**에 `https://github.com/olver1009/knu-audit-hwp`를 입력합니다.
3. **Path**와 **Branch**는 비워 둡니다.
4. **Import marketplace**를 누르고 GitHub 접근을 승인합니다.
5. 가져온 `감사 비용처리서 HWP` 플러그인의 설치 정책을 **Available** 또는 **Installed**로 설정합니다.
6. Plugins 화면에서 플러그인을 설치한 뒤 새 대화를 시작합니다.

## 비용처리서 만들기

새 대화에 아래 자료를 첨부합니다.

- 이번 학기 감사 서식 `.hwp`
- 영수증, 거래명세서 또는 구매내역 이미지/PDF
- 이번 학기 관·항·목 코드표

그다음 다음처럼 요청합니다.

```text
@감사 비용처리서 HWP
첨부 자료로 비용처리서를 작성해.
같은 거래의 같은 목은 합산하고, 다른 목은 별도 HWP로 분리해.
오늘 날짜로 작성하고 원본 HWP 서식은 그대로 유지해.
완성된 HWP를 각각 반환해.
```

Codex에서는 다음처럼 스킬을 직접 지정할 수도 있습니다.

```text
$knu-audit-expense 첨부 자료로 비용처리서 HWP를 작성해.
```

처음 실행하거나 학기 서식이 바뀌었을 때는 새 HWP 양식과 새 코드표를 함께 첨부하세요.
